口令绑定

新设备自动弹窗 · 输入 001 起的槽位口令 · 刷机后直接替换原 MAC

① 节点管理 ② 设备规则与应用 ③ 口令绑定

手机使用方法

1. 手机保持自动获取 IP / DNS，连接当前 Wi-Fi
2. 系统自动弹出绑定页，输入管理员分配的三位口令
3. 绑定成功后自动重连，并获取对应槽位固定 IP

手机刷机或更换后，直接输入原槽位口令即可替换旧 MAC，不需要先在后台解绑。一个口令只对应一个槽位，后输入的设备会替换先前设备。

手动创建口令槽位

槽位会依次获得 001、002、003……口令，并占用当前 LAN 网段中最小的空闲固定 IP。

按已添加节点创建一组口令槽位

每个勾选节点创建一个槽位；再次点击可为相同节点继续创建下一组。

配置生效

新建、修改或删除槽位规则后点击应用配置。日常输入口令换绑只更新 DHCP/MAC，不需要重启 OpenClash。
